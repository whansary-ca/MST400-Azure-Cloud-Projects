# MST400 Azure Cloud Projects

This repository contains hands-on Microsoft Azure projects completed as part of MST400 coursework at Seneca Polytechnic. The projects focus on secure cloud networking, multi-region routing, backup and disaster recovery, and operational monitoring.

## Projects

### 1. Azure Traffic Manager & Point-to-Site VPN

**Folder:** `azure-traffic-manager-p2s-vpn/`

Built and tested Azure cloud networking scenarios involving multi-region traffic routing and secure remote access.

**Key technologies:** Azure Traffic Manager, Azure VPN Gateway, VNets, subnets, NSGs, Azure VMs, Ubuntu, SSH, certificate-based authentication, DNS.

### 2. Azure Backup & Site Recovery

**Folder:** `azure-backup-site-recovery/`

Implemented an end-to-end protection workflow for an Azure VM, including ARM-based deployment, scheduled backup, diagnostic logging, and cross-region replication.

**Key technologies:** Azure Backup, Recovery Services Vault, Azure Site Recovery, ARM templates, Azure VMs, VNets, NSGs, Storage Accounts, diagnostic settings.

### 3. Azure Monitor & Log Analytics

**Folder:** `azure-monitor-log-analytics/`

Configured cloud monitoring and observability using alerts, action groups, alert processing rules, Log Analytics, and KQL queries.

**Key technologies:** Azure Monitor, Log Analytics, KQL, Heartbeat, InsightsMetrics, alerts, action groups, Azure VMs.

## Skills Demonstrated

- Microsoft Azure infrastructure administration
- Cloud networking and secure remote connectivity
- Multi-region architecture and traffic routing
- Backup, recovery, replication, and business continuity
- Infrastructure-as-code concepts using ARM templates
- Cloud monitoring, logging, alerting, and KQL
- Linux and Windows virtual machine administration
- Network and cloud troubleshooting
- Technical documentation and verification
