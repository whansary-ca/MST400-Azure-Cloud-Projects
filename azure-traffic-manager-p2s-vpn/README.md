# Azure Traffic Manager & Point-to-Site VPN

## Overview

This MST400 cloud networking project demonstrates two Azure infrastructure scenarios: multi-region traffic distribution with Azure Traffic Manager and secure remote access using an Azure Point-to-Site (P2S) VPN.

## Project 1 — Azure Traffic Manager

- Deployed Azure virtual machines in multiple regions.
- Configured Azure Traffic Manager to direct client requests between regional endpoints.
- Tested endpoint availability and traffic-routing behavior.
- Worked with Azure networking, DNS-based routing, virtual machines, and regional infrastructure.

## Project 2 — Point-to-Site VPN

- Created an Azure virtual network and supporting subnets.
- Deployed Azure VPN Gateway.
- Configured a Point-to-Site client address pool.
- Implemented certificate-based client authentication.
- Connected a client securely to Azure and verified private connectivity.
- Verified SSH access to an Ubuntu VM through its private IP address.
- Troubleshot certificates, routing, tunnel establishment, NSG rules, and connectivity.

## Technologies

Microsoft Azure, Azure Traffic Manager, Azure VPN Gateway, Virtual Network, Subnets, Network Security Groups, Azure Virtual Machines, Ubuntu Linux, SSH, DNS, X.509 certificates, Point-to-Site VPN.
